# ADR-0005: Stable IDs; labels are for display only (D5)

- **Status:** Accepted, 2026-11-07 (plan v0.6, Phase 1 baseline)
- **Source:** [D5](../03-redesign-plan.md#3-key-decisions)

## Decision

- Every entity has a stable ID; labels are display text only.
- Imports are reconciled: original labels kept, user-confirmed mapping, reviewable diff; no "validated assignment" badge.
- IDs also cover view objects and actors (04 §5).

## Verified by

M1/M2 reconciliation tests.
