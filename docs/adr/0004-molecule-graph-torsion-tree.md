# ADR-0004: Molecule = graph + torsion tree (D4)

- **Status:** Accepted, 2026-11-07 (plan v0.6, Phase 1 baseline)
- **Source:** [D4](../03-redesign-plan.md#3-key-decisions)

## Decision
