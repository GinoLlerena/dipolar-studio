# Verification: synthetic rigid biphenyl (Phase 1 known answer)

**Verification:** `synthetic-only`

| Field | Entry |
|---|---|
| Source and channel | Generated by [`datasets/biphenyl-synthetic/generate.py`](../../../datasets/biphenyl-synthetic/generate.py). Public, BSD-3-Clause. |
| Role | Synthetic known answer. It has no experimental holdout. |
| Model and estimand | Rigid single conformer, with regular hexagonal rings, in the bisector frame. The estimand is the rigid effective inter-ring torsion φ with S_zz and Δ = S_xx − S_yy. N = 14 unique couplings, three free parameters, ν = 11. σ = 0.5 Hz, known and not rescaled ([`expected/spec.json`](../../../datasets/biphenyl-synthetic/expected/spec.json)). |
| Truth | φ = 37°, S_zz = 0.25, Δ = 0.03 ([`truth.json`](../../../datasets/biphenyl-synthetic/truth.json)). |
| Equivalences | At fixed labels, (φ, Δ) and (−φ, Δ) are equivalent. (180° ± φ, −Δ) is equivalent only together with the ring-B relabelling. The domain is folded to [0°, 90°]. |
| Noiseless recovery | Recovers the truth within 1e-8 on φ (degrees), S_zz and Δ ([`expected/noiseless.json`](../../../datasets/biphenyl-synthetic/expected/noiseless.json)). |
| Fixed-noise regression | The frozen fixture's optimum, predictions and intervals, under the regression tolerances of `spec.json` ([`expected/noisy_fixture.json`](../../../datasets/biphenyl-synthetic/expected/noisy_fixture.json)). |
| Coverage | 1000 seeds, within the frozen band for φ, S_zz and Δ ([`expected/coverage_reference.json`](../../../datasets/biphenyl-synthetic/expected/coverage_reference.json)). |
| Reference | [`tools/reference/biphenyl_reference.py`](../../../tools/reference/biphenyl_reference.py), NumPy/SciPy, independent of `dipolar-core`. |
| Criterion | The Phase 1 tolerances in `spec.json`. |
| Robot tutorial | `python -I tools/robot/robot.py --scenario tutorial` (also `web/e2e/tutorial.spec.ts`). |
| Gate evidence | `packages/dipolar-core/tests/test_core_fit.py`, `tests/test_expected_fixtures.py`. |
