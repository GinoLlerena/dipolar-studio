3. **Compare in the paper's frame.** Benzene uses the identity conversion. For ortho-dichlorobenzene, with V1 components \(a=S_{zz}\) and \(c=S_{xx}-S_{yy}\), use \((c-a)/2\) and \(-(3a+c)/2\). Report conditional χ² adequacy, standard errors, and descriptive \(\sqrt{\chi^2/\nu}\)-scaled errors where defined. Keep these diagnostics outside the agreement label. Benzene's rigid-model adequacy can fail while its \(S_{zz}\) comparison agrees.

| Work | Planning estimate |
|---|---:|
| Gate ledger and test freeze, including collinear recovery | 5–8 agent-hours |
| Report workflow, fixtures, report pages and tutorial coverage | 12–20 agent-hours |
| Outside guide, release preparation and installed-wheel rehearsal | 6–10 agent-hours |

| Independent review and fixes | 5–10 agent-hours across steps, subject to findings |
| Owner decisions, two spot-checks, local run setup and evidence, two suite invocations, staged scans, release review, recruitment and external match | 6–10 active owner hours, plus unattended machine time for both suite passes and waits for participants |
| Restricted discrepancy entries and follow-up | 2–6 additional active owner hours as an initial allowance, plus the second human's review time if selected. Re-estimate from the number of disagreements and the first few entries, especially for ODCB anisotropy. |
| Outside session | Allow 1–3 hours for the full 15-condition exercise and adjust the estimate after rehearsal |

Recruitment and publication govern calendar completion. Start recruitment alongside V1.5a. If access to the paper prevents a participant from completing the comparison, record the limitation and recruit another participant who can access it. Library access to the historical geometry references governs only the authors' analysis track. The other material risks are leaking a restricted result through a report attachment or derived quantity, confusing a good numerical match with model adequacy, and allowing local skips or incomplete rosters to turn into green audit rows. Each has a specific gate above.
