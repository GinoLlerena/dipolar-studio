# V0.2 Transcription and verification: the V1 development corpus

**Status: draft for review (2026-11-18).** Two items are still open: the owner's spot-check of
the ortho-dichlorobenzene transcription, and the authors' geometries (library access).

This is the second step of V0 (`docs/phase2-proposal.md`). It follows V0.1
(`docs/phase2/v0.1-selection.md`) and the owner's decision 4 of 2026-11-18: two independent AI
transcriptions, compared mechanically, then spot-checked by the owner.

## 1. Benzene (Taggar et al. 2006): in the repository

**Where:** `datasets/benzene-zli1132-taggar2006/` (README, `source/`, `couplings.csv`).

- **No transcription was needed.** The Supporting Information is a plain-text file, kept byte
  for byte (SHA-256 `a52e77b8…dd29`, 2115 bytes).
- **The CSV.** `tools/datasets/taggar2006.py` derives `couplings.csv`. It parses the benzene
  section and splits each `value(uncertainty)` token into a value and σ, by the last digits. It
  refuses any token that does not match, and checks the source's hash.
- **Completeness:** 15 conditions (7 in Run 1, 8 in Run 2) × D12, D13, D14 = 45 values, each
  with its printed token.
- **Its use.** CC BY-NC 4.0, with attribution and the changes stated in the README. It is
  validation-only: excluded from source archives (`.gitattributes`, and checked in
  `release.yml`), releases and packages. The shipped code never names it
  (`tests/test_boundaries.py`).
- **Tests:** `tests/test_v0_corpus.py` checks:
  - the hash and size;
  - that the CSV equals the parser's output;
  - the counts;
  - each token's reading;
  - one pair per D6h orbit;
  - that a changed token is refused;
  - the export-ignore.

  They skip if the dataset is removed.

## 2. ortho-Dichlorobenzene (Chandrakumar & Burnell 1993): local only

**Where:** `datasets-local/odcb-chandrakumar1993/couplings.csv`, on the owner's machine only.
`datasets-local/` is git-ignored, and a test checks that git ignores it and tracks nothing in it.
**No value of this transcription is in the repository** (© ISMAR; V0.1 §5).

**How it was transcribed** (decision 4):

1. **Two independent transcriptions** of Tables I and II (pp. 201–202) were made from
   high-resolution renderings of the publicly hosted PDF (SHA-256 `f262c2f8…8c99`, in `v0-sources.json`):
   - **A**, by the author agent (Claude);
   - **B**, by a separate Codex task (GPT-6.2-Sol), which was told not to look at any other
     transcription.

   Each recorded the printed tokens verbatim and their numeric reading: `table, T_K, coupling,
   D_token, sigma_token, D_Hz, sigma_Hz`.
2. **A mechanical comparison** (`tools/datasets/compare_transcriptions.py`, exact text
   comparison of every cell, tested) found **87 of 88 cells identical** on the first pass. All
   88 numeric values agreed.
3. **The one difference was a printed token:** Table II, 309 K, D23, the value field. A read
   the separator as a decimal point; B kept the colon-like mark printed there.
   - An 8× zoom of the page shows a colon-like mark, like the one in the uncertainty at 311 K
     (and the PDF's own text layer has a non-decimal separator there). **B was right.**
   - The first-pass comparison output is kept in the local
     `datasets-local/odcb-chandrakumar1993/FIRST-PASS.md`. Only the corrected files survive, so
     the 87/88 count is a reported result, not one that can be re-run.
   - A was corrected, the comparison was repeated, and the two files are now
     **byte-identical**: SHA-256 `d871b1947785f437afe5f4d5bb7fe2fe84d0b05e49e2da6d22994d4186751760`.
4. **The owner's spot-check:** 10 cells chosen at random (seed 20261118) are listed in the local
   `datasets-local/odcb-chandrakumar1993/SPOT-CHECK.md`, for checking against the page.
   **Pending.**

**Completeness:** Table I, 9 temperatures (301–330 K) × 4; Table II, 13 temperatures (288–316 K)
× 4; 88 values with uncertainties.

**Oddities kept as printed:**
- **Two colon tokens**, read as decimals: the uncertainty of Table II, 311 K, D12 = D34, and the
  value of Table II, 309 K, D23.
- **Table II's 300 K and 302 K rows are almost identical**, while neighbouring rows step by
  15–60 Hz. Possible explanations (a temperature label, or a repeated measurement) are not
  resolved. The rows are kept as printed and flagged, and V0.3 decides how they enter the
  comparison.

**What the local README holds.** It carries what V0.1 §3 records:
- the class map (12 = 34, 23, 13 = 24, 14);
- the frame and its map (x, y, z)_V1 = (z, x, y)_paper;
- the J values the source held fixed;
- the unknowns (loading, tubes, co-solutes except the 300 K Table II sample);
- the grouping (one series per mixture).

The same description, without values, is here.
