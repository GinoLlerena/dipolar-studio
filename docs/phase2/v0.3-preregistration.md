# Phase 2 V0.3: the preregistration

**Frozen on 2026-11-19, before any V1 fit of experimental data.** This document and its
machine-readable twin, [`v0.3-preregistration.json`](v0.3-preregistration.json), fix how V1
will fit the two development datasets, what it compares the fits with, and what counts as
agreement. The JSON is authoritative for every number. `tests/test_v0_preregistration.py` checks
it against the code it freezes, and checks its frame conversions on synthetic tensors.

No experimental value has been fitted by V1. **Both datasets are development data**: their
values were seen while selecting and transcribing them ([`exposure-log.md`](exposure-log.md)).
So every comparison below is labelled **"no independent holdout"**. Some choices here were made
after that exposure, and §6 says which.

**The ortho-dichlorobenzene values and its digitized targets stay local** (© ISMAR; V0.1 §5).
This document refers to them only by condition (table and temperature), count, precision and
SHA-256.

## 1. The model

- **The fit** is `dipolar_core.fixed.fit_fixed`, version `fixed-linear.1` (V1.1, tag
  `v1.1-fixed-fit`). Its settings are frozen as they are in the code: the rank thresholds, the
  weak-direction ratio 1e-6, and the adequacy level α = 1e-3.
- **One fit per condition.** Each condition (a sample, at a temperature) is fitted on its own
  couplings. Nothing is pooled across conditions.
- **A rigid, fixed geometry** (§2), an achiral uniaxial medium, ¹H–¹H couplings, and the nuclide
  table `codata2018-iupac.1`. There are no vibrational corrections and no internal motion.
- **The couplings enter as printed:** the published effective D, with their sign, no J
  subtracted, and no factor of 2.

## 2. The declared geometry

The authors' geometries are not available yet. Benzene's comes from Diehl & Niederberger (1973),
ortho-dichlorobenzene's from Diehl & Khetrapal (1968), and both need library access. So V1 fits
with **one declared geometry**:

- **The source:** J. Gauss and J. F. Stanton, *J. Phys. Chem. A* **104**, 2865–2868 (2000), the
  equilibrium structure of benzene: r_e(CC) = 1.3914 Å and r_e(CH) = 1.0802 Å.
- **The shape:** a planar regular hexagon with radial C–H bonds. The ortho H–H distance is
  r_CC + r_CH = 2.4716 Å.
- **For ortho-dichlorobenzene** the same hexagon is used, with H1–H4 on carbons 3–6. Chlorine
  enters no coupling. The real molecule's ring distortions are ignored. That is a known
  approximation, and the in-plane anisotropy S_xx − S_yy is the component most sensitive to it.

## 3. The error model

- **The primary model:** independent Gaussian errors, with σ as printed and at its printed scale.
  No covariance is used, because neither source reports one.
- **Its status.** Both sources leave σ's meaning *unspecified*. Couplings from one spectral fit
  are probably correlated. Every χ², p-value and standard error is therefore **conditional on
  this model**, and is reported as such.
- **A secondary, descriptive report:** standard errors scaled by √(χ²/ν) when ν > 0. This is a
  description of misfit, not a calibrated interval.
- **Adequacy** (the χ² test at α = 1e-3) is reported for every condition. It **does not enter the
  status labels** (§7).

## 4. Benzene (Taggar et al. 2006)

- **Data:** `datasets/benzene-zli1132-taggar2006/couplings.csv`, which has 15 conditions × 3
  couplings.
- **The model:** D6h, so there is one order parameter S_zz, with z normal to the ring. The pair
  orbits are D12 (H1–H2), D13 (H1–H3) and D14 (H1–H4). That gives 3 observations, d = 1 and ν = 2.
- **The estimand:** S_zz for each condition, in the paper's frame. That frame is also V1's D6h
  frame.
- **The targets:** the paper's Tables 1–2, which give S_zz with its printed uncertainty, for all
  15 conditions.
  - The paper is © ACS, so the targets are a local file
    (`datasets-local/benzene-taggar2006-targets/targets.csv`, SHA-256 `af653a83…efcfb`).
  - They are read by `tools/datasets/taggar2006_targets.py`, as **two independent readings of the
    PDF's text layer** (pypdf's text flow, and pdfminer's positioned lines). The readings are
    identical, token for token.
  - Their condition keys are exactly the SI's 15.
- **Flags:**
  - the four mixed samples (`1/mix1`, `2/mix2.1`, `2/mix2.2`, `2/mix2.3`) share their tubes with
    co-solutes;
  - run 1's single-solute series shares one tube, so those conditions are not independent
    samples.

  Both are reported; neither excludes a condition.
- **Known before the fit (disclosed).** V0.1 found that the measured D13/D12 and D14/D12 are about
  1 % above the rigid hexagon's ratios. The printed σ are of order 10⁻⁵ relative. So the χ² test
  under the primary error model **is expected to reject the rigid model** for benzene. That is a
  statement about rigidity, about vibrational averaging and about the spectral assumptions. It is
  not about the implementation. It is reported, and it does not set the label (§7).

## 5. ortho-Dichlorobenzene (Chandrakumar & Burnell 1993)

- **Data:** the local `datasets-local/odcb-chandrakumar1993/couplings.csv`. It has 22 conditions
  (Table I: 9 temperatures; Table II: 13) × 4 couplings.
- **The model:** C2v. The four pair orbits are D12 = D34, D13 = D24, D14 and D23, so N = 4, d = 2
  and ν = 2.
- **The frame.** The fit runs in V1's C2v frame: z on the C2 axis, x and y in the mirror planes.
  The map to the paper's frame is (x, y, z)_V1 = (z, x, y)_paper. With a = S_zz and c = S_xx − S_yy
  in the V1 frame:
  - S_zz (paper) = (c − a)/2;
  - S_xx − S_yy (paper) = −(3a + c)/2.

  Both conversions are tested on a synthetic tensor fitted through the same map.
- **The estimands:** S_zz and S_xx − S_yy in the paper's frame, for each condition.
- **The targets are digitized,** because the paper gives its order parameters only as plotted
  points.
  - **Fig. 3** (against T_r = T/T_NI, with T_NI = 333 K for Table I and 317 K for Table II) plots
    filled markers only. Each panel has exactly 9 triangles and 13 squares, so **every condition
    has a target in both components**.
  - The tool is `tools/datasets/digitize_figure.py`. It decodes the embedded scan losslessly,
    fits each frame's four edges, and calibrates along the 14 ticks of each vertical side, so the
    scan's skew is corrected.
  - Markers are classified by size and fill, and the legend is excluded. Two overlapping pairs in
    S_zz (a stacked pair, and a side-by-side pair) are split using the known marker size. Their 4
    targets carry the flag `overlap-resolved`.
  - **Assignment is by rank** within each series, since the counts match.
- **The checks of the digitization:**
  - **The temperature axis.** Each marker's own T_r agrees with T/T_NI within 0.0009. The closest
    pair of conditions is 0.0032 apart.
  - **The axis ticks.** The tick residuals are below 0.00025 in value.
  - **The Fig. 2 cross-check.** **Fig. 2** plots the same results against T, with open symbols
    beside them. Where a filled marker stands alone, it is compared with the Fig. 3 target: that
    is 17 of 22 S_xx − S_yy targets and 1 of 22 S_zz targets (Fig. 2a's filled markers sit on top
    of the open "recalculated" symbols). The largest difference is 0.37 of the summed precisions.
  - **The rule for a disagreement:** a disagreement with Fig. 2 beyond twice the summed precisions
    would make that target *pending*. None does.
- **The declared precision of each target:** half a pixel, plus the tick residual. A triangle
  adds h/6, because its bounding-box centre and centroid differ by that much. A split pair adds
  one pixel.

  | Component | Squares (Table II) | Triangles (Table I) |
  |---|---|---|
  | S_zz | 0.00027 to 0.00049 | 0.00087 to 0.00108 |
  | S_xx − S_yy | 0.00027 to 0.00028 | 0.00084 to 0.00092 |
- **The result:** 44 targets, 0 pending. The local file is
  `datasets-local/odcb-chandrakumar1993/targets.csv`, SHA-256 `1c7327c2…0b14f`.
- **Table II's 300 K and 302 K rows** are almost identical (V0.2). Both enter as printed, as two
  conditions, each against its own target. A pre-specified sensitivity check (§7) recomputes the
  dataset's label without each one.
- **Other flags:**
  - the 300 K Table II sample also contained trichlorobenzene;
  - the two colon tokens are read as decimals (V0.2);
  - the transcription is two identical AI transcriptions, and **the owner's spot-check is
    pending**. Until it is done, every comparison carries that note. A correction found by the
    spot-check is a data correction, allowed under §8.

## 6. The agreement criteria

Two kinds of comparison are kept apart, as the V1.5 report requires.

**Independent support** compares V1's fit, made with the declared geometry, against the published
values:
- S_zz: |S − S_pub| ≤ 0.05·|S_pub| + 2p;
- S_xx − S_yy: |S − S_pub| ≤ 0.05·|S_zz,pub| + 2p.

Here p is the target's precision: its printed σ (benzene), or its digitization precision
(ortho-dichlorobenzene).

**Why 5 %.** The declared geometry is not the authors'. Common benzene structures differ by up to
about 1 % in the H–H distance (r_e against r_α against an LC-NMR r_D), which is about 3 % in S.
The authors' SHAPE fits also weight the couplings in ways not yet known; the rigid ratios are
about 1 % off, and so are their implied scales. 5 % covers both, with a margin. **It was chosen
after exposure:** V0.1's scale check on one benzene row implied an ortho distance of 2.4778 Å,
against the 2.4716 Å declared here, which is about 0.75 % in S.

So agreement under this criterion supports the implementation and the declared-geometry model
together. It is not a precision test.

**Reproduction** uses the authors' geometry and objective. It stays **pending** until those are
obtained (library access). Then:
- for a table, |S − S_pub| ≤ max(printed σ, half a unit in the last printed digit);
- for a figure, |S − S_pub| ≤ 2p.

If the authors' weights remain unknown, V1 uses 1/σ² and says so. A failure then reads "not
reproduced, objective unknown".

## 7. Labels and aggregation

- **Per condition and component:** *agrees*, *disagrees*, or *pending* (no target).
- **Per dataset and kind of comparison:**
  - **experimentally supported:** every compared target agrees. The number of pending targets is
    stated.
  - **unresolved failure:** a compared target disagrees, and its dataset README has no reviewed
    entry for it.
  - **explained discrepancy:** a disagreement with a reviewed README entry (estimand, geometry,
    vibrational corrections, solvent). It is **not counted as validation**.
  - **pending:** nothing can be compared.
- **Every label carries** "development data, no independent holdout", and for
  ortho-dichlorobenzene the spot-check note while that is open.
- **Sensitivity (ortho-dichlorobenzene).** The label is recomputed without II/300 K and again
  without II/302 K. If either changes it, the result is reported as *fragile*.
- **Not part of any label:** adequacy, the ratio residuals and the scaled standard errors. They
  are reported beside it.

## 8. Amendments

A change to anything above is an **amendment**: a dated entry in the JSON's `amendments` and in
this document, with its reason.
- An amendment made **before** the affected fit is preregistered.
- One made **after** it is labelled *post hoc* wherever its result appears.
- **A data correction** (a transcription error found by the owner's spot-check, say) is allowed,
  and recorded the same way.
- **A target-list correction** (a re-digitization, say) is allowed before the fit. After it, it
  is post hoc.

## 9. Reproducing the targets

Both commands are run from the repository root, with the two PDFs from `v0-sources.json` in
`datasets-local/sources/`. Their checksums are verified by the tools.

```sh
uv run --with pypdf==7.1.1 --with pillow==13.0.0 python tools/datasets/digitize_figure.py \
    --pdf datasets-local/sources/chandrakumar-burnell-1993-bmr-issue.pdf \
    --couplings datasets-local/odcb-chandrakumar1993/couplings.csv \
    --out datasets-local/odcb-chandrakumar1993/targets.csv
uv run --with pypdf==7.1.1 --with pdfminer.six==20260107 python tools/datasets/taggar2006_targets.py \
    --pdf datasets-local/sources/taggar-2006.pdf --out datasets-local/benzene-taggar2006-targets/targets.csv
```

Each command prints the SHA-256 recorded above. `tests/test_digitize_figure.py` checks the
digitizer on synthetic skewed scans: the markers, the stacked and side-by-side splits, and the
refusal of a missing tick.
