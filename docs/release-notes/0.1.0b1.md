# Dipolar Studio 0.1.0b1 (beta)

<!-- Absolute links: this file is also the GitHub release's text (.github/workflows/release.yml). -->

The first public beta of Dipolar Studio: the conformation (the inter-ring torsion) and the
orientational order (the Saupe order matrix) of a biphenyl-type molecule in a liquid crystal, from
its NMR dipolar couplings. It is a new implementation of the scientific idea of the 1998
graduation thesis of **Gino Llerena and Marco Idrogo** (advisor **Dr. Jaime Avalos**), developed
with AI assistance.

**Testers:** start with the [testers' guide](https://github.com/GinoLlerena/dipolar-studio/blob/main/docs/beta/testers.md).

## Install

Python 3.12 or newer; the two wheels of this release (the browser app is bundled):

```bash
pip install dipolar_core-0.1.0b1-py3-none-any.whl dipolar_app-0.1.0b1-py3-none-any.whl
dipolar serve --project-dir ~/dipolar/my-project --open
```

## What it does

- **Fits** with honest statistics: weighted least squares over every coupling, a multi-basin
  search, validity flags judged separately (convergence, adequacy under the stated σ,
  identifiability, physical admissibility), standard errors and profile intervals where the fit
  supports them, and the estimand stated with every result.
- **Models:** for the built-in biphenyl template, rigid and the symmetric four-site jump; for
  your own XYZ geometry, rigid with the c2z or c1 order model.
- **Your data:** couplings from a CSV (with σ), reconciled with the molecule's protons through a
  mapping you confirm; geometry from the template or an XYZ file.
- **The browser app:** Data, Fit (live preview of the torsion, the χ² landscape, residuals, jobs),
  Structure (the molecule with each coupling coloured by its misfit) and Proposals; undo and redo;
  results marked stale after a change.
- **Reports:** each fit as a self-contained HTML page and a full-precision CSV; the same fit gives
  the same report.
- **Python:** `dipolar_app.api.Studio`, the same operations as the app, in a notebook or a script;
  three executed [notebooks](https://github.com/GinoLlerena/dipolar-studio/blob/main/docs/notebooks/README.md).
- **Reproducible by construction:** a journal of every change (with its actor), immutable runs
  with their provenance, plain-text project files.
- **Ready for AI agents (Phase 3):** every action is a typed operation of one registry; agents can
  propose changes that a human accepts; a scripted robot user proves it in the tests.

## Known limits

- Biphenyl-type molecules (two rings, one torsion), ¹H–¹H dipolar couplings only. Other molecule
  classes, measurement types and models are Phase 2.
- The structure view renders SVG, not PNG.
- The live preview is interactive for projects of a few hundred couplings; at tens of thousands it
  takes seconds.
- A camera move made immediately after another one can be refused and lost; move again.

## Validation

Every step was reviewed independently (GPT-6.1-Sol, at most two rounds per step), and the
findings and fixes are recorded in [docs/validation/](https://github.com/GinoLlerena/dipolar-studio/tree/main/docs/validation). The engine's answers are
checked against frozen results from an independent reference implementation: exact recovery on
synthetic data, interval coverage calibrated on 1 000 noise realizations, and the published 8CB
couplings (Di Pietro, 2013), which Dipolar Studio does not ship.
