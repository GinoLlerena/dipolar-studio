# Dipolar Studio 0.2.0b1 (beta)

<!-- Absolute links pinned to the tag: this file is also the GitHub release's text (.github/workflows/release.yml). -->

The Phase 2 pre-release of Dipolar Studio. Besides the biphenyl-type molecules of 0.1, it fits the
orientational order of a **rigid molecule** from its own XYZ geometry and a declared point group.
It is the release for the outside benzene reproduction exercise
([the guide](https://github.com/GinoLlerena/dipolar-studio/blob/v0.2.0b1/docs/phase2/reproduce-benzene.md)).

## Install

Python 3.12 or newer, in a fresh environment; the two wheels of this release (the browser app is
bundled):

```bash
pip install dipolar_core-0.2.0b1-py3-none-any.whl dipolar_app-0.2.0b1-py3-none-any.whl
dipolar --version
dipolar serve --project-dir ~/dipolar/new-project --open
```

`dipolar --version` prints `dipolar 0.2.0b1 (dipolar-core 0.2.0b1, contract 0.12.0)`: the tool
contract is 0.12.0.

## Projects from 0.1

Use a new directory for each 0.2 project. A directory written by Dipolar Studio 0.1 is refused,
and it is not changed. To carry a project over, open it with 0.1, export it (Data → Export, or
`project.export`), and load the file into a new directory with 0.2. Undo history, runs and
proposals stay in the old directory, which 0.1 still opens.

The 8CB beta exercise keeps using 0.1.0b1 and
[its testers' guide](https://github.com/GinoLlerena/dipolar-studio/blob/v0.2.0b1/docs/beta/testers.md),
whose links are pinned to that release.

## What is new

- **Fixed geometry.** A rigid molecule with no torsion, from your XYZ file:
  - declare its point group (C1, Cs, C2v, D2h, D3h or D6h) and its axes; the declaration is
    checked against every atom;
  - import one coupling per pair orbit;
  - fit the order tensor. The fit is linear, so its intervals are exact.

  The result names the estimable combinations, the components fixed by symmetry, the rank and
  whether it is verified, the adequacy and the admissibility. The
  [getting-started guide](https://github.com/GinoLlerena/dipolar-studio/blob/v0.2.0b1/docs/user/getting-started.md)
  works through a synthetic 1,4-dichlorobenzene example.
- **The project format** is schema v3, and the contract is 0.12.0. Results carry no torsion when
  the model has none.
- **The browser app** has the symmetry form, the fixed-geometry model, and a structure view along
  the declared axes. The robot user's tutorials cover every model (rigid, fixed and the four-site
  jump).

## Validation

Every step was reviewed independently, and the findings and fixes are recorded in
[docs/validation/](https://github.com/GinoLlerena/dipolar-studio/tree/v0.2.0b1/docs/validation).
The fixed-geometry fit recovers known answers exactly on synthetic data, including the
collinear rank-1 case, in two frames. The release workflow checks these wheels before drafting:
the user's path, and a synthetic D6h fit run from outside the source tree.
